## 📌 Description

This project is a cybersecurity tool that monitors network traffic by capturing packets flowing through the system. It analyzes packet information and displays important network details such as IP addresses, MAC addresses, ports, and protocols.

---

## 🚀 Features

* Captures live network packets
* Detects source and destination IP addresses
* Detects source and destination MAC addresses
* Identifies TCP and UDP protocols
* Displays packet details in real time
* Saves packet information to a log file
* Supports basic network traffic monitoring
* Uses Scapy for packet analysis

## ▶️ How to Run


3. Install Npcap (Windows)

4. Open terminal in project folder

5. Run:

   ```bash
   python packet_analyzer.py
   ```
